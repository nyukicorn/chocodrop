# ChocoDrop サイト試作 — 2026-09-19

## 目的と範囲
公開サイトを置き換える前に、全体構成と色合いをブラウザで相談するための独立した試作。
- Dark: 添付1枚目の紫がかったチャコール、ラベンダー、アイボリー。
- Light: 添付2枚目のクリーム、淡いピンク、ココア。
- トップ、世界一覧、使い方、Codex / Claude Code連携、対応状況の5画面。
- トップは生成コンセプト画像。世界一覧は実際の公開デモのスクリーンショット。
- デモ自体のデザイン、MCP実装、ブックマークレットの修理・再公開は今回の対象外。
- 公開もpushもしていない。Pagesビルド対象外。

## 起動
リポジトリルートから:

```sh
python3 -m http.server 8097 --bind 127.0.0.1 --directory prototypes/bloom
```

http://127.0.0.1:8097/ を開く。静的HTML/CSS/JavaScriptのみ。
