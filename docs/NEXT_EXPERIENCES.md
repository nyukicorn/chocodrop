# 次の体験づくり

現行のブラウザ版は、初めての人がBasicデモで素材を1つ置けるところまでを完成条件とします。次の機能はこの入口を壊さず、段階を分けて進めます。

## 1. 世界をつなぐ地図

- 7つの公開世界を、気分と見た目で選べる1枚の地図にまとめる。
- 各地点から既存の「この世界へ」リンクを開く。
- 最初から全世界を読み込まず、サムネイルと説明を先に表示する。

完了条件は、スマートフォンでも全世界を選べて、同じ世界の重複表示がなく、戻る操作で地図へ復帰できることです。

## 2. 新しい紹介動画

- 現在のブラウザImport、ローカルMCP、Codex・Claude Code・Antigravityとの連携だけを紹介する。
- KAMUI Codeを前提にした旧映像や字幕は使わない。
- まず30〜45秒の短い版を作り、READMEとトップページで同じ動画を使う。

完了条件は、初見の人が「手元の画像・動画・GLBをThree.js空間へ置く道具」だと動画だけでも理解できることです。

## 3. XR版

- ブラウザ版とは別の実験版として扱い、Meta Quest実機で検証する。
- WebXR対応、操作方法、性能、配布方法を確認してから公開導線へ加える。
- Quest Storeへの提出は、WebXR版の利用状況と実機検証の後に判断する。

XRはブラウザ版の公開を止めません。現状と検証手順は[xr_auto_requirements.md](xr_auto_requirements.md)と[quest-testing.md](quest-testing.md)に分けて残します。
